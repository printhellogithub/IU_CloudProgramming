2. Daten, die für die Bereitstellung der Website und die Erstellung der
Protokolldateien verarbeitet werden
a. Welche Daten werden für welchen Zweck verarbeitet?
Bei jedem Zugriff auf Inhalte der Website werden vorübergehend Daten gespeichert, die
möglicherweise eine Identifizierung zulassen. Die folgenden Daten werden hierbei
erhoben:
- Datum und Uhrzeit des Zugriffs
- Amazon Cloudfront Edge-Standort, der die Anfrage bearbeitet hat
- Ob die Antwort gecached war, oder vom Server abgerufen werden musste
- IP-Adresse
- Ländercode des geografischen Standortes anhand der IP-Adresse
- HTTP Request Methode
- HTTP Status Code der Serverantwort
- Website, von der aus die Website aufgerufen wurde
- Wert des User-Agent-Header in Anfrage z.B. Gerätetyp, Browser oder genutzte Suchmaschine
- Informationen über den Browsertyp und die verwendete Version
- Betriebssystem
- Zeit in Sekunden, die der Server von Anfrage bis zum letzten Bit der Antwort benötigt hat
- Besuchte Seite auf unserer Website
- Übertragene Datenmenge
